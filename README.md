# Intro to Git and GitHub

This repository contains the presentation materials for the Intro to Git and GitHub workshop conducted on 09/29/2026.

### Workshop Overview

The workshop is a beginner friendly introduction to Git, the version control tool, and GitHub, the website that hosts Git projects. It covers why version history matters for any project, setting up Git, cloning a repository, pulling changes, making commits, pushing to GitHub, opening pull requests, and writing a README in Markdown.

### Setup

Install [Git](https://git-scm.com/downloads) and make a free [GitHub](https://github.com/) account.
